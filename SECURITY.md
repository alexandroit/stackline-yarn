# Security

Report vulnerabilities privately using the repository's GitHub Security Advisories
interface: https://github.com/alexandroit/stackline-yarn/security/advisories/new .
Do not put credentials or private registry contents in public issues.

This fork supports Node >=20.19.0 and normal npm installation with its declared
runtime dependencies. Keep the dependency graph current and audit the actual
installed lockfile. A copied standalone cli.js is not supported.
